# 📊 Power BI Sales Dashboard

## 🔍 Project Overview
This project is an interactive Power BI dashboard designed to analyze sales performance, track KPIs, and generate business insights.

## 🚀 Features
- Sales trend analysis
- Region-wise performance
- Top products & categories
- KPI metrics (Revenue, Profit, Growth)
- Interactive filters & slicers

## 🛠️ Tools Used
- Power BI
- Excel / CSV Dataset
- Data Cleaning & Transformation
